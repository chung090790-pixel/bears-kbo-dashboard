최신 경기는 수집 실패 시 마지막 정상 JSON을 유지합니다.

운영 메모

  • GitHub Pages는 docs/ 산출물을 배포합니다.
  • 자동 실행은 .github/workflows/daily.yml 의 UTC cron 기준입니다.
  • 로컬 버튼은 app.py 의 POST /refresh 엔드포인트를 호출합니다.
  • KBO 페이지는 공식 공개 API가 없고 ASP.NET hidden input / POST 파라미터를 요구할 수 있어 서버 측 수집이 필요합니다.
